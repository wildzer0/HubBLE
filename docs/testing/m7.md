# M7 manual hardware checklist (power management)

Setup as `m3.md`: B68 and EM06 paired, dongle on the computer under test, web app open on a phone. Watch the System page
log (it shows `host suspended: low-power mode` / `host awake: full speed`).

## A. Suspend and resume

- [ ] Put the computer to sleep. After about 2 s the log shows low-power mode; the LED goes off; the AP switches off
      (the Wi-Fi network disappears) unless an update is running.
- [ ] Device page (open it before sleeping, or after waking): while asleep the negotiated interval was about 40 ms and the
      latency 10 (check the log or reconnect the page after waking). Note what the B68 and EM06 really accepted.
- [ ] Wake the computer from the keyboard (see B). Within a second the interval is back to 7.5 ms with latency 0.
- [ ] A short idle suspend (a few seconds, e.g. USB selective suspend) does not trigger low power when shorter than the
      debounce.

## B. Remote wakeup

- [ ] With the setting ON, pressing a B68 key wakes the sleeping computer; the waking key is NOT typed. Same with a click
      and with trackball movement. Note the delay between the key press and the wake-up (expected up to about 0.4 s).
- [ ] With the setting OFF (Settings page, before sleeping) nothing wakes the computer.
- [ ] A computer or BIOS with USB wake-up disabled: nothing happens, and nothing breaks after waking manually.
- [ ] No keys stay stuck after waking up (held keys during the suspend are released).

## C. LED

- [ ] Patterns match `power.md`: amber pulse without devices, blue breathing with the AP on, cyan blink while pairing,
      magenta in quarantine, purple during an update, off when a device is connected.
- [ ] Brightness 0 turns it off; 100 is clearly brighter; "dim green" shows while a device is connected.
- [ ] LED is off while the computer sleeps, whatever the other state.

## D. AP

- [ ] With no device paired the AP is normally always on; it still goes off while the computer sleeps and returns after waking.
- [ ] An update started before sleeping keeps the AP up.
- [ ] The Ctrl + Alt gesture time set in Settings (for example 5 s) applies after a dongle restart.

## E. Measurements (record in `power.md`)

- [ ] Battery current of the B68 and EM06, dongle active vs. computer asleep for several minutes.
