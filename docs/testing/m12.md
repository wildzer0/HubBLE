# M12 manual hardware checklist (configuration over USB)

First time this runs on a board, so go step by step and keep the System page log (Wi-Fi) or the serial log at hand. Needs: a
PC with Chrome or Edge, the dongle with the 1.3.0 build, the paired B68 and EM06.

## 0. Enabling

- [ ] The feature is off by default: with it off the PC sees the **two** HID interfaces the dongle always had. Turn on
      Settings → Configure over USB, restart, and the PC sees **three**.

## A. The USB device is still healthy

- [ ] After the update the PC still enumerates the dongle (Device Manager / `lsusb`): `303a:4001` with **three** HID interfaces
      (keyboard, control, vendor `0xFF00`). If it does not enumerate or the keyboard stops working, update back over Wi-Fi
      (the AP is on for the first minutes after power-up) and tell us.
- [ ] Typing on the B68 and the trackball still work, also in the BIOS if you can check.
- [ ] Remote wakeup and suspend still behave (`m7.md` A and B).

## B. Connecting

- [ ] Open <https://wildzer0.github.io/HubBLE/app/> in Chrome/Edge. The gate asks to connect the dongle.
- [ ] *Connect the dongle* opens the browser's list with **HubBLE**; choose it. The app loads the Devices page.
- [ ] Linux only: without the udev rule the device is missing from the list; with it, it appears.
- [ ] Close the window after the boot window (5 min) with nothing happening: connecting shows "the configuration window is
      closed". BOOT, Ctrl + Alt or replug reopens it.
- [ ] While the page is open and in use the window does not close by itself.

## C. Using the app over USB

- [ ] Devices, Settings, System load. Change a setting, save, reload the page, reconnect: it persisted.
- [ ] Pair a device (passkey or challenge): the page follows the progress (it polls once a second).
- [ ] Input tester: events appear while it is on. System: the log shows history and new lines.
- [ ] Download the log and the backup file. "Prepare a report" works on a connected device.
- [ ] Update from a file over USB: the progress bar moves and the dongle restarts into the new version (slow: about a minute).
      A wrongly signed image is refused.
- [ ] "Wi-Fi off now": the USB page keeps working while the Wi-Fi is off.
- [ ] Unplug the dongle while the page is open: the app returns to the connect screen.

## D. Numbers to record

- [ ] How long a 1.3 MB firmware upload takes over USB; how long the first connection takes.
- [ ] Whether typing latency (Devices page) changes while the page is connected and the tester is on.
