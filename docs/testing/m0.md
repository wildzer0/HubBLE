# M0 manual hardware checklist (optional first-flash test)

M0 has no hardware gate. If you have a board, verify the skeleton:

- [ ] Board identifies as an ESP32-S3 (not C3) when plugged in with BOOT held.
- [ ] `factory.bin` flashes at `0x0` without errors.
- [ ] After replug, the LED flashes white for ~0.3 s (S3-Zero) / lights briefly (XIAO).
- [ ] Serial monitor (USB Serial/JTAG) shows the banner with the correct version and board id.
- [ ] Log line `Embedded web bundle: ... files` is shown.
- [ ] Record any deviation (LED colour order, GPIO) in `docs/hardware.md`.
