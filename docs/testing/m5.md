# M5 manual hardware checklist (web app)

Same setup as `m3.md`/`m4.md`. Use a phone on the dongle's Wi-Fi (and a desktop browser once). The web app itself is
covered by unit and Playwright tests against the mock API; this list checks it against the real firmware.

## A. First run

- [ ] After a factory reset (or first flash) every page redirects to the setup wizard.
- [ ] A password shorter than 10 characters, or the default one, cannot be submitted; a good one is accepted and the
      Wi-Fi restarts (the phone must rejoin with the new password).
- [ ] Step 2 shows two QR codes. The first one, scanned with the phone camera, joins `HubBLE-XXXX` with the new
      password; the second opens `http://hubble.local`. The Print button produces a clean page with only the codes.
- [ ] "Pair the first device" leads to the pairing page.

## B. Dashboard and pairing

- [ ] Cards show name, type, connection state, battery, RSSI, security badge and the measured latency.
- [ ] Pair the B68 and the EM06 from the web app, following `m4.md`; the passkey, the click sequence with progress, the
      confirm hint and the countdown match what the dongle does. A failed pairing shows a readable reason.
- [ ] Three failed pairings show the lock message and disable "Scan" for 60 s.

## C. Device detail

- [ ] Rename and forget work; the connection interval shows the negotiated value (7.5 ms target).
- [ ] "Export report map" downloads a `.hex` file. Save the B68 and EM06 files as
      `firmware/test/fixtures/yunzii-b68.hex` and `protoarc-em06.hex` (this unblocks the real-fixture parser tests).
- [ ] With the device switched off, the export reports that it is not connected.

## D. Input tester

- [ ] Start: typing on the B68 shows the keys (with modifiers); the EM06 shows movement, wheel and buttons.
- [ ] Stop (or leaving the page, or closing the tab) ends the stream within about 15 s; nothing appears afterwards.
- [ ] While the stream runs, typing latency (Dashboard) does not get worse in a noticeable way.

## E. Settings, backup, factory reset

- [ ] Changing the physical-confirmation switch persists across a reboot. A boot window / idle timeout change takes
      effect after the next reboot.
- [ ] Downloaded backup contains only the three settings. Restoring a file made on another dongle works; a wrong file
      is rejected with a clear message.
- [ ] Factory reset (with confirmation) reboots into the first-run state and all devices are gone (no auto reconnect).

## F. Language and accessibility

- [ ] Italian/English switch in Settings applies to every page. Tab through each page: focus is always visible and
      "Skip to content" appears first.
